# Movie Ticketing System (C)

Sistem biletash kinemaje në C — shtim, shfaqje, modifikim, kërkim dhe fshirje e rezervimeve të biletave.

`C`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Movie-Ticketing-System/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Kompilo me `gcc main.c -o movie` dhe ekzekuto `./movie`.
